# Development Readiness Gate

PASS requires:

- approved PRD or Delta PRD;
- required design artifacts or waiver;
- architecture/API/data contracts appropriate to scope;
- Plan and tasks with acceptance and technical checks;
- working runtime and baseline commands;
- test strategy;
- external providers, configuration fields, credential ownership, and Mock
  fallback confirmed;
- migration and rollback when applicable;
- explicit instruction to start development.
