# ECC V2 Bugfix

Read `harness-core/workflows/bugfix.md`. Record the issue under
`.sdd/bug_fix/`, retrieve relevant experience, reproduce, identify root cause,
add a failing regression test when possible, implement the smallest safe fix,
run Reviewer and Tester, update the bug log, and capture reusable experience.
