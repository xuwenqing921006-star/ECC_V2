# Archive and Delete Workflow

Archive is preferred when the user only wants to stop active work.

Before deletion:

1. Resolve the exact project path.
2. Show project identity, path, Git state, external links, and deletion scope.
3. Offer archive or registry-only removal.
4. Require explicit confirmation naming the project.
5. Use the Windows project command; never a broad recursive shell expression.
6. Update the registry atomically.
7. Report what was removed and whether recovery is possible.
