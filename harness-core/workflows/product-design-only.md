# Product, Design, and Documentation Workflow

Use when the requested outcome is a brief, PRD, user journey, flow, Design Spec,
prototype, architecture proposal, or document without production coding.

Select only required phases:

- unclear idea: Product Brief + R;
- product definition: R + A;
- interface design: A + B1 + B2;
- technical handoff: C;
- documentation repair: inspect facts, update document, verify references.

Clearly label artifacts as Draft, Proposed, Approved, or Superseded. Do not
present an unapproved design as implemented behavior.
